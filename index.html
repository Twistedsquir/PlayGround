Native PC games (Steam etc.)?

Browsers can't inject keys into other desktop programs directly. Two proven bridges:
① Keep the game in a browser tab and tether that tab.
② Map the keys shown above in JoyToKey / AntiMicroX / Steam Input to your controller, or forward via the WebSocket snippet in app.js (InputBridge.broadcast).

iPhone / iPad (iOS apps)?

iOS Safari blocks capturing other apps' windows, and web pages can't overlay native apps — so:
① Web URL mode is the fully playable option: the web game runs inside the stage and overlay controls send it keys.
② Camera mode: point the camera at your console/PC screen — great for laying out controls and for companion-style play.
③ For native iOS games, mirror the iPhone to a Mac/PC (e.g. via AirPlay/QuickTime), open this page on that computer, and tether that mirrored window.
